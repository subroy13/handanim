A class representing a sketch animation event that progressively renders drawing operations.

This animation supports partial rendering of drawing and fill operations with configurable timing and optional glowing dot effects. It allows for smooth, incremental visualization of drawing sequences.

Bases: AnimationEvent

Atomically swaps source out and target in at start_time.

If duration == 0.0 (default), performs an instant Hide(start_time) on source and Show(start_time) on target. If duration > 0.0, cross-fades between them.

Usage:

# or
scene.swap(closed_mouth, open_mouth, 1.2)

handanim.animations.camera¶

class handanim.animations.camera.CameraAnimation(start_time=0.0, duration=0.0, easing_fun=None, data=None)[source]¶

Bases: AnimationEvent

Animates the Scene viewport (pan and/or zoom) over time.

Instead of touching any drawable’s OpsSet, this animation changes the world ranges that the Viewport maps to the screen — the “camera” moves, not the content.

Parameters:

  • start_time – When the animation begins (seconds).

  • duration – Length of the animation (seconds).

  • easing_fun – Optional easing function applied to progress.

  • data (dict) –

    Dict with optional keys:

    • "from_xrange" (tuple[float, float]): World x range at progress=0. Defaults to wherever the camera currently is.

    • "from_yrange" (tuple[float, float]): World y range at progress=0. Defaults to wherever the camera currently is.

    • "to_xrange" (tuple[float, float]): World x range at progress=1. Defaults to from_xrange (no movement on x).

    • "to_yrange" (tuple[float, float]): World y range at progress=1. Defaults to from_yrange (no movement on y).

Usage:

scene.add_camera(CameraAnimation(
    start_time=5, duration=3,
    data={
        "to_xrange": (400, 800),
        "to_yrange": (200, 600),
    }
))

class handanim.animations.transitions.SceneTransition(start_time=0.0, duration=1.0, easing_fun=<function ease_in_out_cubic>, data=None)[source]¶

Bases: AnimationEvent

Base class for scene-level page transitions (PageTurnTransition, PaperCrumpleTransition).

When added to a Scene via scene.add_transition(transition) or scene.add(transition):

  • All world drawables created before transition.start_time belong to the outgoing page and are automatically deactivated at transition.end_time.

  • Any world drawables created at or after transition.start_time belong to the newly revealed page underneath.

  • Camera-invariant scene.overlay drawables (e.g. Captions) remain untouched above the page.

Parameters:

  • start_time (float)

  • duration (float)

  • data (dict)

class handanim.animations.transitions.PageTurnTransition(start_time=0.0, duration=1.0, direction='right_to_left', bleed_through=0.16, flap_color=None, border_color=(0.32, 0.3, 0.27), shadow_opacity=0.14, easing_fun=<function ease_in_out_cubic>, data=None)[source]¶

Bases: SceneTransition

Folds and turns the current drawing sheet across the board to reveal the next page.

Supported direction values: - "right_to_left" (default): Lifts the right side of the paper and folds it left. - "left_to_right": Lifts the left side of the paper and folds it right. - "bottom_right" (or "right_corner_to_left_corner"): Peels the bottom-right corner diagonally across to top-left. - "bottom_left" (or "left_corner_to_right_corner"): Peels the bottom-left corner diagonally across to top-right. - "top_right": Peels the top-right corner diagonally across to bottom-left. - "top_left": Peels the top-left corner diagonally across to bottom-right. - "bottom_to_top": Flips the bottom edge of the notepad upward. - "top_to_bottom": Flips the top edge downward.

Parameters:
