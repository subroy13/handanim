Adds an animation event to a drawable primitive in the scene.

Handles different scenarios including: - Self-driving drawables such as Captions (e.g. scene.overlay.add(captions)) - Swap(a, b, t) events (e.g. scene.add(Swap(a, b, t))) - Composite animation events (recursively adding sub-events) - Drawable groups with parallel or sequential event distribution - Single event and drawable cases
