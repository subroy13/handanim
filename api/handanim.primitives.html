handanim.primitives.character.solve_two_joint_ik(root_pos, mid_pos, end_pos, target_pos, bend_direction=1)[source]¶

Solve 2D two-bone analytic inverse kinematics using the Law of Cosines.

Given rest joint positions (root_pos, mid_pos, end_pos) and a desired target_pos (in the same coordinate frame as root_pos), returns the local rotation angles (upper_angle_deg, lower_angle_deg) for a parent-child bone pair so that end_pos reaches target_pos (or stretches toward it if out of reach).

Parameters:

  • root_pos (tuple[float, float]) – Rest position of the root joint (e.g. shoulder or hip).

  • mid_pos (tuple[float, float]) – Rest position of the middle joint (e.g. elbow or knee).

  • end_pos (tuple[float, float]) – Rest position of the end effector (e.g. wrist/hand or ankle/foot).

  • target_pos (tuple[float, float]) – Desired position for the end effector.

  • bend_direction (int) – +1 or -1 selecting which side the middle joint bends toward.

Returns:

Tuple (upper_angle_deg, lower_angle_deg) in degrees.

Return type:

tuple[float, float]

An auto-routed arrow between two flowchart nodes.

Computes an elbow route from from_node.get_anchor(from_side) to to_node.get_anchor(to_side) at draw time so that moving a node automatically updates the connector without re-construction.

For straight lines (same axis, opposing sides, perfectly aligned), a single Arrow is drawn. Otherwise an L-shaped elbow is used: the connector exits from_node in the from_side direction, turns once at the midpoint, then arrives at to_node from the to_side direction.

class handanim.primitives.table.Table(top_left, n_rows, n_cols, cell_width, cell_height, data=None, headers=None, cell_font_size=12, header_font_size=14, stroke_style=<handanim.core.styles.StrokeStyle object>, sketch_style=<handanim.core.styles.SketchStyle object>, fill_style=None, header_fill_style=None, header_stroke_style=None, **kwargs)[source]¶

Bases: DrawableGroup

A grid of Rectangle + Text cells with optional header-row styling.

Each cell is a DrawableGroup([rect, text]) stored in self.cells[row][col]. Row groups (self.row_groups[r]) contain the leaf rect/text drawables for all cells in that row — they are kept flat (no nested DrawableGroups) so that group-level scene animations apply correctly.

The Table itself is a flat parallel DrawableGroup of all leaf drawables, so scene.add(event, table) animates every cell simultaneously.

Parameters:

  • top_left (tuple[float, float]) – (x, y) world coordinates of the table’s top-left corner.

  • n_rows (int) – Total rows, including the header row if headers is provided.

  • n_cols (int) – Number of columns.

  • cell_width (float) – Width of each cell in world units.

  • cell_height (float) – Height of each cell in world units.

  • data (list[list[str]] | None) – 2-D list of cell strings, indexed [row][col]. Rows with a header start at data[0] = row 1 of the grid. Missing entries default to “”.

  • headers (list[str] | None) – Column header strings for row 0. If provided, row 0 uses header_stroke_style / header_fill_style instead of the defaults.

  • cell_font_size (int) – Font size for data cells.

  • header_font_size (int) – Font size for header cells.

  • stroke_style (StrokeStyle) – Stroke style for data cells.

  • sketch_style (SketchStyle) – Sketch style shared by all cells.

  • fill_style (FillStyle | None) – Fill style for data cells (None = no fill).

  • header_stroke_style (StrokeStyle | None) – Override stroke style for header cells.

  • header_fill_style (FillStyle | None) – Override fill style for header cells.
