handanim.stylings.fonts.register_font(name, file_path, font_type='ttf', persist=False)[source]¶

Register a TTF or custom JSON font for use in Text and Math.

By default (persist=False), registers the font in memory for the current Python process without modifying ~/.handanim/config.json.

Parameters:

  • name (str) – Identifier to use as font_name (e.g. “kalam”).

  • file_path (str | Path) – Path to the .ttf or .json font file.

  • font_type (str) – Either “ttf” (default) or “custom”.

  • persist (bool) – If True, also saves the registration in ~/.handanim/config.json.

Returns:

The resolved absolute path to the registered font file.

str

Bases: HachureFillPattern

Fills polygons with a zigzag line pattern — like back-and-forth colored pencil shading.

Takes the same hachure lines as HachureFillPattern, then subdivides each line into segments and offsets midpoints perpendicular to the line direction, alternating sides. The zigzag_offset field in FillStyle controls the amplitude; when negative, defaults to the hachure gap.

handanim.utils.humanize¶

handanim.utils.humanize.bow_segment(start, end, amplitude)[source]¶

Return (c1, c2) cubic Bézier control points that bow a segment naturally.

Both control points share the same perpendicular displacement (no S-curve inflection) and sit at a shared random diverge fraction in [0.2, 0.4], matching the technique used in Line.draw_single_line.

amplitude: maximum perpendicular displacement in world units.

Parameters:

  • start (tuple[float, float] | ndarray)

  • end (tuple[float, float] | ndarray)

  • amplitude (float)

Return type:

tuple[ndarray, ndarray]

handanim.utils.humanize.apply_roughness(ops, roughness, font_size)[source]¶

Replace LINE_TO segments with naturally bowed CURVE_TO segments.

Amplitude = roughness * sqrt(length * font_size / 24), which keeps roughness dimensionless (≈ % of font_size for a full-height stroke) while giving shorter segments proportionally less wobble. Uses bow_segment so both control points bow consistently to one side.

Parameters:

  • ops (OpsSet)

  • roughness (float)

  • font_size (float)

Return type:

OpsSet
