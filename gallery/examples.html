Examples & Visual Gallery¶

Explore complete runnable scripts in the examples/ directory of the repository.

Mathematical Proofs & Geometry¶

1. Pythagoras Theorem (examples/pythagoras.py)¶

Demonstrates polygon construction, rotated square alignment, hachure fills, and sequential SketchAnimation reveals.

poetry run python examples/pythagoras.py

2. Visual Proof of \((a + b)^2\) (examples/a_plus_b_square.py)¶

Demonstrates geometric partitioning of a square into \(a^2\), \(b^2\), and two \(ab\) rectangles alongside step-by-step algebraic equations.

poetry run python examples/a_plus_b_square.py

3. Distributive Property (examples/distributive_property.py)¶

Shows grouped drawable transformations, TranslateToAnimation, and equation derivations.

Flowcharts & Diagrams¶

4. Machine Learning Workflow (examples/ml_workflow_demo.py)¶

Demonstrates FlowchartNode, FlowchartDiamond, FlowchartConnector, and Table animations.

poetry run python examples/ml_workflow_demo.py

Short-Form Storytelling: Characters, Captions & Sound¶

5. Character Rig, 2-Joint IK & Expressions (examples/character_rig_demo.py)¶

Demonstrates a 9:16 portrait scene featuring:

  • Hierarchical CharacterRig (torso -> head -> eyes/mouth)

  • Analytic 2-joint inverse kinematics (TwoJointLimb) reaching for whiteboard points

  • Swappable VariantSlot eye blinks (open / blink / wink) and mouth shapes (neutral / talk / smile)

  • Smooth keyframe interpolation via PoseAnimation

  • Instant Show, Hide, and Swap events

poetry run python examples/character_rig_demo.py

6. Built-In Captions, Camera Overlay & Soundtrack (examples/captions_overlay_demo.py)¶

Demonstrates:

  • Word-timed Captions pinned to scene.overlay

  • CameraAnimation zooming into a diagram while the overlay HUD and captions remain stationary

  • Repeating "marimba" background theme music (background_music=”marimba”)

  • Automatic chalk drawing sound during SketchAnimation (sketch_sound=True) and board-wiping sound during Eraser (eraser_sound=True)

poetry run python examples/captions_overlay_demo.py

7. Multi-Page Scene Transitions (examples/scene_transitions_demo.py)¶

Demonstrates a 3-page sketchbook story using:

  • PageTurnTransition folding Page 1 from the bottom-right corner with ink bleed-through on the backside flap

  • PaperCrumpleTransition grabbing a “wrong draft” on Page 2, crunching all its strokes into a multi-faceted 3D paper ball, and tossing it off to the right to reveal Page 3

  • Persistent header badge pinned to scene.overlay

  • Automatic page_turn and crumple procedural sound effects (transition_sound=True) combined with sketch_sound=True and background_music="calm"

poetry run python examples/scene_transitions_demo.py

8. LaTeX Beamer & Native TikZ Export (examples/tikz_beamer_demo.py)¶

Demonstrates exporting an animation directly to a compilable LaTeX Beamer presentation using inline TikZ commands (export_beamer()).

poetry run python examples/tikz_beamer_demo.py
